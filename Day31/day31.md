# Day 31 - AI Supply Chain Control Tower

## Project Overview

The AI Supply Chain Control Tower is an interactive operations simulation where the player acts as the Head of Operations.

The objective is to monitor supply chain disruptions, prioritize operational alerts, select corrective actions, and maintain strong business performance before the simulation ends.

## Features

- Real-time operational alerts
- Multiple simultaneous incidents
- Priority-based alert system
- Live KPI dashboard
- Service Level tracking
- Customer Satisfaction tracking
- Inventory Health tracking
- Transportation Efficiency tracking
- Operating Cost tracking
- Revenue Protected tracking
- Dynamic score system
- Countdown timer
- Live event log
- Pause and resume
- Sound toggle
- Help and instructions modal
- Final performance dashboard
- Performance grading system
- Replay functionality
- Responsive design

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

No React, Vue, Angular, Tailwind, Bootstrap, APIs, or backend services were used.

## Gameplay

The player receives operational incidents such as:

- Port Congestion
- Supplier Delay
- Truck Breakdown
- Warehouse Stockout
- Customs Inspection
- Demand Spike
- Factory Machine Failure
- Weather Disruption
- Wrong Inventory Count
- Damaged Shipment

Each incident provides different corrective actions.

The selected action affects the operational KPIs, score, cost, and revenue protected.

## Key Learnings

1. Learned how to design an interactive operations dashboard.
2. Learned how to manage multiple real-time alerts using JavaScript.
3. Learned how business decisions can affect multiple KPIs.
4. Learned how to create a dynamic countdown-based simulation.
5. Learned how to implement priority-based visual alerts.
6. Learned how to build a responsive dashboard using HTML and CSS.
7. Learned how to structure JavaScript into reusable functions.
8. Learned how to create game-over and replay functionality.
9. Learned how to simulate delayed consequences of operational decisions.
10. Learned how AI-style decision support can be represented in a supply chain control tower.
