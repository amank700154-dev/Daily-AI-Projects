Day 38 — Typing Speed Studio

Project

Typing Speed Studio — Creative Writing Edition

A premium offline typing-practice application focused on creative writing.

What I completed

Chose Creative Writing as the category.

Let Claude automatically decide the features.

Generated and saved a single-file HTML application.

Opened the application locally in a browser.

Tried multiple typing modes and completed several sessions.

Reviewed live typing statistics, analytics and session history.

Captured screenshots of the main application states.

Main Features

Time Mode: 15 / 30 / 60 / 120 seconds

Word Count Mode: 25 / 50 / 100 / 250 words

Quote, Custom Text and Zen modes

Focus Mode

Dynamic creative-writing passages

WPM, Raw WPM, CPM, accuracy, mistakes and streak

Completion and remaining-time/word indicators

Character-level feedback

Pause/resume and restart

Optional sound effects and theme controls

Responsive design and keyboard shortcuts

Local session history with localStorage

WPM/accuracy graphs, error heatmap and consistency analysis

Achievement badges and personalized suggestions

Key Learnings

Speed is not the only useful measurement; accuracy and consistency provide important context.

Different modes train different skills.

Varied creative passages make practice more engaging.

Analytics turn each session into actionable feedback.

Local storage provides useful offline history without an account.

Polished interaction design makes practice feel less like an exam.
