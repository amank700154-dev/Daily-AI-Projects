# Day 26 - Prior Authorization Workflow Simulator

## Project Overview

Built a single-file Prior Authorization Workflow Simulator using HTML, CSS, and vanilla JavaScript.

The simulator demonstrates the US healthcare Prior Authorization workflow through an interactive, gamified drag-and-drop experience.

## Features

- Three workflow lanes:
  - Patient
  - Provider
  - Payer
- Multiple patient scenarios
- Elective surgery scenario
- MRI scenario
- Specialty medication scenario
- Inpatient admission scenario
- Medical necessity evaluation
- PA document collection
- Submission to payer
- Payer review
- Pend / additional information
- Approval
- Denial
- Appeal
- Peer-to-peer review
- Drag-and-drop workflow
- Progress tracker
- Days elapsed counter
- Efficiency score
- Educational explanations
- Workflow activity log
- Approval celebration animation
- Workflow completion summary
- Restart / New Patient functionality
- Responsive design

## Technologies Used

- HTML
- CSS
- Vanilla JavaScript

No frameworks, CDNs, external dependencies, localStorage, or build tools were used.

## What I Learned

- How prior authorization workflows are structured.
- How to model a multi-stage workflow using JavaScript state.
- How to implement HTML5 drag-and-drop interactions.
- How to dynamically update UI components.
- How to create multiple scenarios from reusable JavaScript data.
- How to build an educational simulator with gamification.
- How to manage workflow outcomes such as approval, pend, denial, and appeal.
