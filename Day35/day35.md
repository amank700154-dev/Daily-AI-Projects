# 🧩 Day 35 — Prompt Puzzle

## 🚀 Project Title

**Prompt Puzzle — Master AI Prompting Through Play**

Day 35 of the **60 Days Claude AI Challenge**.

This project is an interactive browser-based game designed to help users improve their AI prompting skills through practical challenges.

---

## 🎯 Objective

The goal of this project is to learn how to create better AI prompts by practicing:

- Prompt structure
- Context setting
- Role definition
- Clear instructions
- Output formatting
- Constraints
- Avoiding unnecessary complexity
- Comparing weak and optimized prompts

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Drag & Drop API
- Responsive UI
- Browser Local Execution

The application is contained in a **single HTML file** and works offline.

---

## 🧩 Features

### 1. Build the Prompt

Users receive multiple prompt blocks and must select the correct blocks to construct an effective prompt.

The challenge evaluates:

- Correct blocks
- Distractors
- Wrong placements
- Number of moves
- Hints used

---

### 2. Clean the Prompt

Users are given a weak prompt and must improve it.

The challenge focuses on adding:

- Specific context
- Role
- Clear objectives
- Constraints
- Output requirements

---

### 3. Choose the Best Prompt

Users compare three prompts:

- Weak Prompt
- Optimized Prompt
- Over-Engineered Prompt

The objective is to identify the prompt that provides the best balance between **specificity and simplicity**.

## 🧠 Key Learnings

### 1. Be Specific

A vague prompt such as:

> "Analyze this."

usually produces a generic response.

Adding context and a clear objective produces much better results.

---

### 2. Define the Role

Using instructions such as:

> "Act as a senior UX designer."

helps establish the perspective and expertise expected from the AI.

---

### 3. Define the Audience

The AI should know who the response is intended for.

For example:

> "Explain this to a beginner who knows basic arrays."

This changes the complexity and language of the response.

---

### 4. Specify the Output

Instead of asking:

> "Create a marketing plan."

A stronger instruction could specify:

- Number of ideas
- Target audience
- Channels
- Tone
- Format

---

### 5. Use Constraints

Constraints help prevent unwanted results.

Examples:

- Do not invent information.
- Keep the answer concise.
- Use bullet points.
- Provide three alternatives.
- Avoid unnecessary jargon.

---

### 6. Avoid Over-Engineering

Adding too many roles, instructions, requirements, and unnecessary details can make a prompt harder to follow.

The goal is not to make the longest prompt.

The goal is to make the **clearest useful prompt**.

---

## ✨ Prompt Formula

A useful prompting structure learned from this project is:

**Role + Context + Task + Constraints + Output Format**

Example:

Act as a beginner-friendly programming instructor.

Explain binary search to a student who understands basic arrays.

Use a simple real-world analogy and one worked example.
