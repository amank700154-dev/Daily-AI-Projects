Day 36 — Cognitive Pattern Explorer

Project Overview

Cognitive Pattern Explorer is a single-file, offline psychology-inspired self-reflection web app built with HTML, CSS, and vanilla JavaScript.

The experience is designed to feel calm and exploratory rather than like a clinical test. It uses reflective language and explicitly avoids diagnosis or clinical assessment.

Features Completed

Calm Mode and Stress Mode

Chapter 1 interactive everyday scenarios

Five reflective thinking tendencies

Chapter 2 draggable priority cards

Chapter 3 draggable thinking-sequence timeline

Personalized percentage breakdown

Reflection Journal with local browser storage

Replay/reset functionality

Progress indicator

Responsive desktop/mobile layout

Keyboard focus states and semantic controls

Reduced-motion support

No frameworks or external dependencies

Fully offline single-file HTML

Key Learnings

State management makes interactive flows easier to maintain.

Reusable drag-and-drop logic reduces duplicated interaction code.

Reflective scoring should be framed as an exercise result, not a psychological diagnosis.

Accessibility needs to be considered during implementation, not added at the end.

A single HTML file makes offline testing and sharing straightforward.

Responsive grids and flexible typography keep the experience usable on smaller screens.
