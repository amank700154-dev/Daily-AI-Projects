# Operation Lifeline — Supply Chain Crisis Lab

## Project
**Operation Lifeline: Supply Chain Crisis Lab** is a React-based interactive simulation for practicing supply-chain crisis management.

### Technologies
- HTML5
- CSS3
- React 18
- ReactDOM 18
- Babel Standalone

### Features represented in the supplied source
- Randomized company profiles
- Eight supply-chain crisis scenarios
- Crisis impact metrics
- War-room response actions and trade-offs
- Decision/AI review
- Final scoring and feedback
- Responsive dark dashboard UI

# Project Overview

## Purpose
Operation Lifeline is an interactive supply-chain crisis decision lab. The learner receives a company profile, faces a disruption, selects response actions, reviews metric impact, and receives a final assessment.

## Company simulation
The source randomizes industry, company name, revenue, factories, warehouses, suppliers, inventory days, lead time, and operating countries.

## Crisis scenarios
1. Factory Fire
2. Supplier Bankruptcy
3. Port Strike
4. Cyberattack
5. Flood
6. Raw Material Shortage
7. Political Conflict
8. Shipping Delay

Each scenario has urgency, metric impacts, a generated incident description, and a business-impact explanation.

## War-room actions
The visible source defines:
- Air-Freight Emergency Stock
- Activate Backup Supplier Network
- Ration Inventory to Key Accounts
- Delay Non-Critical Orders
- Raise Prices to Offset Losses (definition is truncated)

## Metrics
- Cost
- Inventory
- Profit
- Delivery
- Customer Satisfaction

## Design
The supplied CSS uses a dark navy visual system, blue/purple gradients for primary actions, teal positive accents, red critical states, rounded cards, hover transitions, and a mobile breakpoint at 640px.
