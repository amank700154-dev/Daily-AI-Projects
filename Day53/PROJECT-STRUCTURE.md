# Defend Your Experience — Project Structure

## Verified Current Structure
```text
Daily-AI-Projects/
└── Day50/
    ├── day50.html
    └── day.md
```

## `day50.html`
The single application file containing HTML, CSS, JavaScript, Dashboard, My Claims, Defense Interview, Defense Report, Session History, Settings, evidence input, claim extraction, local storage, theme switching, exports, Anthropic API interaction, and fallback questioning.

## `day.md`
Project requirements and design source covering purpose, audience, claim-defense framework, adaptive interview logic, integrity rules, technical features, and required screenshots.

## Architecture Rule
The source explicitly requires a single self-contained HTML file using HTML/CSS/JavaScript only. Do not introduce a backend, database, Node project, or unnecessary folders unless an approved project document changes this requirement.
