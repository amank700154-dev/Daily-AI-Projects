## Key Learnings

### 1. AI should be part of a workflow
The goal is not to let AI blindly build an application. A stronger process is:

**Specify → Generate → Inspect → Run → Test → Refine**

### 2. Context matters
AI coding results improve when the prompt contains the existing code, project conventions, requirements, constraints, expected behavior and relevant evidence.

### 3. Verification is essential
Generated code should be reviewed and tested. Security, architecture decisions, secrets and production behavior require deliberate verification.

### 4. Small changes are safer
Small implementation steps and clean Git commits make AI-assisted development easier to review, debug and roll back.

### 5. Production UI needs states
A good interface includes loading, empty, error, validation, responsive and accessibility states—not only the happy path.

### 6. Automation should target repetition
Useful future automation includes issue-to-plan generation, regression-test creation, PR summaries, release notes, recurring dependency/security checks and documentation drafts.
