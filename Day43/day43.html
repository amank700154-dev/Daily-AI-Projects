Tool selection logic

Need fast UI?

Use an AI coding assistant to generate a first pass, then manually refine responsive behavior and accessibility.

Need correctness?

Give AI tests, constraints, expected inputs/outputs and existing code before asking for a fix.

Need research?

Ask AI to compare options against explicit criteria instead of asking for “the best” tool.

Need deployment?

Use AI for configuration and troubleshooting, but verify secrets, domains, builds and logs yourself.

Workflow Summary

Plan → Design → Build → Verify → Ship → Improve

The goal is not “let AI code everything.” The goal is to create a repeatable engineering loop where AI handles high-leverage drafting, exploration and diagnosis while you own requirements, trade-offs, security and final verification.

Additional AI Prompts

  • Architect: “Turn these requirements into a React architecture. State assumptions, component boundaries, data flow, risks and trade-offs before proposing code.”
  • Implement: “Implement this component with clear props, accessible semantics, responsive behavior and minimal dependencies. Explain only non-obvious decisions.”
  • Debug: “Here is the error, reproduction, expected behavior and relevant code. Identify likely root causes, rank them, then propose the smallest safe fix and a regression test.”
  • Review: “Review this change as a senior frontend engineer. Check correctness, accessibility, performance, security, maintainability and edge cases. Separate blockers from nice-to-haves.”
