# Day 27 — Prior Authorization Story Simulator
## Project
Prior Authorization Story Simulator

## What I built
An interactive HTML story simulator that follows Rahul's healthcare journey through the prior authorization process. The application contains eight scenes and lets the user choose between two dialogue options after each stage.

## Key Features
- 8-scene interactive healthcare journey
- Rahul as the patient and Priya as the operations specialist
- Two choices at each major scene
- Progress bar showing the current scene
- Explanatory information cards
- Prior authorization review, denial, appeal, and approval flow
- Final patient and system takeaways
- Restart button to explore different dialogue paths
- Responsive browser-based UI using HTML, JavaScript, Tailwind CSS, and simple animations

## Story Flow
1. Doctor Visit
2. Insurance Roadblock
3. What is Prior Authorization?
4. Insurance Review
5. Denial
6. Appeal
7. Approval
8. Takeaways

## Learnings
- Interactive storytelling can make a complex healthcare workflow easier to understand.
- A progress indicator helps users understand where they are in a multi-step process.
- Branching choices can make an educational application more engaging.
- Clear information cards are useful for explaining technical or administrative concepts.
- JavaScript functions can be used to manage scenes, choices, progress, and restart behavior in a single-page application.

## Tech Stack
