# Future Scope — Defend Your Experience

## Purpose

These are post-v1.0 directions, not features that already exist. Future work should preserve the core principle:

> **Defend, don't decorate.**

## 3 months

### Deployment hardening
- Verify and document a production-safe Anthropic authentication architecture.
- Keep secrets out of browser source.
- Add stronger deployment checks.

### Claim quality
- Improve extraction and duplicate detection.
- Allow claim editing/merging.
- Add clearer evidence fields.

### Defense modes
- Technical-depth mode
- Behavioral mode
- Project-defense mode
- Portfolio/research mode

### Evaluation transparency
- Explain why each dimension received its score.
- Show evidence associated with each dimension.
- Track improvement across repeated sessions.

## 6 months

### Role-specific simulations
Adapt probing to a selected role context without inventing user experience.

### Team contribution analysis
Separate team work from the user's personal ownership, decisions and evidence.

### Deeper technical probing
Move from what was built to implementation, alternatives, failures, measurement and trade-offs.

### Long-term practice analytics
Track claims practiced, dimensions improving and recurring evidence gaps without turning the product into a large analytics platform.

## 12 months

### Multimodal defense
Potentially use screenshots, architecture diagrams, selected code snippets and project documentation as evidence.

### Voice interview mode
Add spoken practice while retaining the claim-centered defense model.

### Personalized defense curriculum
Turn recurring evaluation gaps into structured practice plans.

### Broader contexts
Support internships, placements, project vivas, research discussions and portfolio reviews.

## Scope guard

Every future feature should directly improve claim defense, evidence discovery, adaptive questioning, evaluation or repeat practice. Technically interesting features that do not strengthen that loop should remain separate product directions.
