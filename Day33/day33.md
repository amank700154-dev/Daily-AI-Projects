# Day 33 – Media Integrity Analyzer

## Project Overview

Created a **Media Integrity Analyzer**, an interactive offline web application designed to teach media literacy through guided discovery.

The application helps users recognize:
- Misleading or exaggerated headlines
- Emotional manipulation
- Audience targeting
- The difference between claims and supporting evidence
- Neutral ways to rewrite persuasive content

## Features

### 1. Theme Selection
Users can choose from multiple visual themes:
- Claude Orange
- Signal Blue
- Insight Mint
- Focus Violet

### 2. Headline Detective
Users investigate a fictional news headline by:
- Deciding whether they would click it
- Identifying exaggerated or misleading parts
- Comparing the headline with the article
- Viewing a Headline Accuracy Score
- Reviewing highlighted mismatches
- Reading a fair rewritten headline
- Learning the key media-literacy takeaway

### 3. Emotion Detector
Users analyze a fictional social media post by:
- Identifying their emotional reaction
- Selecting words that influenced their reaction
- Discovering the target audience
- Identifying the intended emotional response
- Understanding the manipulation technique
- Reviewing highlighted emotional phrases
- Comparing the original with a neutral rewrite

### 4. Live Media Integrity Metrics

The application updates four metrics during the investigation:

- **Headline Accuracy**
- **Source Reliability**
- **Emotional Manipulation**
- **Audience Targeting**

### 5. Media Integrity Dashboard

The final dashboard provides:
- Overall Media Integrity Score
- What the user learned
- Biggest red flag
- Three practical media-literacy habits
- Replay functionality with new randomized scenarios

## Key Learnings

1. **Don't judge a story only by its headline.**  
   Read the article and compare the headline's claim with the actual evidence.

2. **Strong emotions can influence judgment.**  
   Fear, anger, excitement, and urgency can make people react before verifying information.

3. **Look for emotionally loaded language.**  
   Words such as "outrage," "secret," "huge," and "before it's too late" can influence how a message is perceived.

4. **Consider the target audience.**  
   Content is often framed differently depending on the people it is trying to reach.

5. **Separate facts from framing.**  
   A message can contain a real fact while presenting it in a misleading or exaggerated way.

6. **Pause before sharing.**  
   Taking a few seconds to verify a claim can prevent misleading information from spreading.
